# Proof

Proof is a native iOS app for tracking projects, milestones, and accomplishments so developers can turn their work into a portfolio.

## Current beta

- SwiftUI interface
- SwiftData persistence
- Project creation
- Milestone tracking
- Progress calculation
- Accomplishment/activity log
- Portfolio view
- Light/dark mode through the system appearance
